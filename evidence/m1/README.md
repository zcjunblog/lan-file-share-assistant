## 能证明与不能证明

本机基础能力确实经过有限探针；二维码确实被独立解码。二维码内容为example.invalid合成字符串，不对应任何已启动服务。本机bind成功只说明当前调用具备绑定条件，不能证明手机连通、防火墙放行或AP允许互通。

有限进程存活只覆盖当前Codex执行工具两次调用之间约12秒，不能证明聊天结束后、机器睡眠后或WorkBuddy内的长期服务能力。时钟变化只校验参考判定规则，尚未验证真实服务到期中断和监听关闭。

期限协议已要求服务采用经过核对、包含系统休眠的连续计时来源；后端未知时不承诺睡眠后准时失效。Mac原生API的可调用性与厂商语义分开记录，物理睡眠、Windows/Linux计时后端和真实强制到期仍待后续验证。

云端、容器、沙箱、Windows/Linux及其他客户端只形成了设计分支与合成案例，不是对应环境实际运行记录。文件身份探针使用合成资料，只验证相关OS原语，不代表M2白名单/快照安全流程已经实现。

## 复现与资料处理

项目虚拟环境依赖见requirements-m1.txt；核心二维码运行选择仅Segno，jsonschema、Pillow与zxing-cpp为本轮验证依赖。没有修改系统或宿主全局Python配置，没有修改防火墙、路由、VPN或本地网络设置。

原始environment.json、心跳、进程归属及生成图片留在被Git忽略的outputs/m1。tools/summarize_m1.py仅输出白名单中的版本、计数和布尔结果，不复制本机IP、接口名、端口号、绝对路径、PID或随机归属标识到仓库。

重新运行探针时选择新的输出目录，避免覆盖历史。生命周期探针固定12秒自行退出，待结束后再生成摘要；不要使用它作为生产预检放行凭证。
