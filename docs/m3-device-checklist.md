# M3 外部设备验收清单

日期：2026-11-06。当前本机与WorkBuddy开发包链路通过；以下项目保留为待验收，不自动启动会话或更改系统设置。

## 已取得的手机结果

用户已用同网手机取得合成文件验收码，且停止分享后确认旧链接无法再次打开。手机系统/浏览器未提供，不将其写成某个机型的兼容结论。源码SHA-256只能说明本地源文件，不能替代手机保存副本的摘要。

后续有条件时，在手机上对实际保存文件计算SHA-256，与同一会话源快照摘要逐字比较；记录手机系统、浏览器、保存文件大小及结果。若没有可用的手机摘要工具，保持“内容回读通过、字节摘要未验证”，不为补证据安装不明应用。

## 整机睡眠恢复

用户本轮已选择暂不睡眠。未来选择不会中断其他工作的时间，再进行以下流程：

1. 只生成并授权一份合成文本，不选择真实工作资料。
2. 重新probe，下一次独立工具调用预检并启动60秒会话，再独立核验ready。确认不存在其他尚需保持运行的任务。
3. 由用户手动让电脑睡眠约90秒并唤醒；不能以SIGSTOP服务进程代替整机睡眠。
4. 唤醒后先检查旧会话状态、下载拒绝、监听关闭与临时资源清理，记录实际经过时间及用户确认。
5. 如果系统休眠/恢复或进程状态无法确认，保留未验证或失败，不复用旧凭据，不通过修改截止时间“修复”结果。

不自动调整睡眠设置、不改系统时间、不对其他应用发送信号。

## 操作系统及其他客户端

当前macOS后端可运行；Windows/Linux后端尚未实现并完成验收。注入平台标签只验证拒绝反馈，不证明真机行为。需要在实际系统中补齐安全文件/权限、接口发现、含休眠连续计时及同样的停止/过期验收后，才允许放行和标注支持。

新的Agent客户端先核实本地执行位置、解释器/二维码依赖与跨调用进程能力；按Skill先预检，再用合成文件执行真实下载、摘要核验和到期关闭。安装成功与运行通过分别记录。

正式WorkBuddy发布包在M4完成后，还需解压独立运行、最终包安装烟测与平台解析；开发ZIP通过不代表市场审核通过。
